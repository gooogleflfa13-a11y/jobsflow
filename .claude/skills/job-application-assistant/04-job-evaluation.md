# Job Evaluation Framework

Evaluate each role against the private candidate profile and the full JD.

## Inputs

- Core evidence: [YOUR_PRIMARY_SKILLS]
- Qualifications and work authorization: [YOUR_ELIGIBILITY]
- Career direction: [YOUR_TARGET_DIRECTION]
- Schedule/location constraints: [YOUR_CONSTRAINTS]
- Compensation expectations: [YOUR_COMPENSATION]

## Required output

1. Evidence-backed strengths.
2. Hard eligibility gaps.
3. Requirements that need user confirmation.
4. Direction, industry, work-mode, and compensation fit.
5. Confidence based on JD depth.

Do not use a built-in candidate biography. A missing private profile is a
blocker, not permission to assume credentials or preferences.
